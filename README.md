# GameZone - Webzine de Videojuegos

## Descripción

GameZone es una página web informativa desarrollada como proyecto académico de Ingeniería Multimedia. Su objetivo es presentar contenido relacionado con el mundo de los videojuegos mediante un diseño moderno, atractivo y responsivo.

El sitio incluye artículos sobre videojuegos populares, una galería de imágenes, un video promocional de GTA VI, una sección con información de la autora, enlaces a plataformas de videojuegos y un formulario de suscripción para los visitantes.

## Tecnologías utilizadas

- HTML5
- CSS

## Características

- Diseño moderno con temática gamer.
- Menú de navegación interactivo.
- Artículos con imágenes y descripciones.
- Galería de videojuegos.
- Video integrado de YouTube.
- Barra lateral con información de la autora.
- Formulario de suscripción.
- Diseño adaptable a dispositivos móviles.
